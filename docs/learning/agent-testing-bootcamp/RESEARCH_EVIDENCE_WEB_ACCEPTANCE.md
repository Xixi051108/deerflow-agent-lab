| _solve1_browser_search_url（2506）、get_nodriver_browser（2375） | HTTP结果不足后再用浏览器等待DOM并读取 | 该主链浏览器主要读取搜索引擎页；商品详情仍主要HTTP抓取。它不证明小米购买页已能渲染并切换配置 |

不可照搬的实际点：

- SOLVE1_NOISE_DOMAINS（2308附近）包含jd.com／taobao.com／tmall.com；其事实核查过滤目标不同，直接搬来会丢掉我们的销售来源。
- 详情正文默认最多2000字符，通用快速抓取还有1800字符上限。金额／配置可能位于后部，需要继承本项目分段和分页能力。
- XPath分支遇到第一个长度至少80字符的结果便返回，元描述可以比实际商品正文先被接受；长度达标不等于价格槽位齐全。
- 全局Windows事件循环切换、全局浏览器、自动可见启动、日志及dotenv覆盖，不适合直接移入Gateway。DeerFlow已有按线程隔离的browser_automation及URL检查，若补浏览器，应优先复用这些能力。
- curl_cffi的HTTP请求不能执行页面JavaScript。它的TLS兼容策略不能当动态页面渲染或验证码解决方案。浏览器、代理池和其他依赖均未在本轮安装。
- AFC“无明确反证”对应其分类任务的默认标签，不代表我们能够把未知价格认证为真；现有unknown／gap边界继续保留。

### 离线对比结果

用之前保存的2条京东HTML和3条官网响应，按AFC源码的XPath顺序、最小80字符与截断2000字符策略单独复现；没有执行其网络、浏览器或trafilatura分支。当前backend环境未安装trafilatura、curl_cffi、nodriver、playwright，BeautifulSoup与lxml已存在。

- 两条京东响应均先命中约100字符的meta描述，仍未保留3099.00／4099.00；按AFC当前fallback原样搬用不能修复此次样本。
- 去除script／style等后的完整HTML正文文本包含两条金额，证明**本地正文保留与提取质量判断值得采用**。这只是离线候选验证，尚未替换生产提取器，也不保证所有页面可用。
- 官网空壳仍无法凭解析器恢复商品数据；移动页的原始body XPath甚至可能选中脚本内容，须保留清洗与不可信来源边界。需另测浏览器渲染，不能宣称AFC已解决。

产物afc-capture-comparison.json、复核脚本afc_capture_comparison.py；离线自检通过，没有新增网络或模型调用。参考文件SHA256：README.md为 `c7a8733dee2f4beb60e4aa22dcf359475936df722f8b77883a18b62ca4fedd37`，solve.py为 `909f6aeb83ba2ce7aa9183be156764e724776c55fb6dae795677b0cde44dc35d`。

当前采用结论：**借鉴中文检索、证据缺口驱动补读、失败分类及多策略提取的思路；先用已有BeautifulSoup／Markdown能力修复研究采集正文保留，再以实际空壳复测决定浏览器后备。** 本轮完成实测与参考评审，没有移植AFC主程序或修改生产代码。
