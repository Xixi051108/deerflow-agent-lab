## 6. 经历复盘与两版简历

对 AFC、lighthouse-openclaw、dcma-agent 分别填写：对象与目标、本人职责、实现/测试方法、一个实际问题、可公开证据、AI/他人/框架贡献。忘记的细节填“待确认”，不推测公司内部实现。

- Agent 版：在【实际项目】负责【本人模块】，沿【已有链路】实现【行为】，用【实际测试】验证【边界】，结果【有依据的事实】。
- 测试开发版：针对【实际风险】设计【有记录的场景】，实现【本人自动化】，定位【实际问题】，经【实际回归】验证【结果】。

两版都只写实际完成的工作；不使用未经测量的效率提升、覆盖率或项目规模。

## 7. 五分钟演示与模拟面试

演示：30 秒问题与本人职责 → 60 秒原有链路和新增点 → 90 秒真实运行/工具证据 → 90 秒失败测试与修复 → 30 秒限制和下一步。

Agent 面试：模型和工具谁执行？schema 如何绑定？state/checkpoint 有何区别？何时终止？工具失败在哪里处理？如何区分事实与模型编造？

测试面试：用例从哪里来？为何选此测试层？mock 掩盖什么？如何判定自然语言答案？怎样证明断言有效？不稳定测试如何定位？CI 失败如何复现？

每轮记录：问题、本人回答、缺失证据、纠正后的答案、闭卷重答日期。
