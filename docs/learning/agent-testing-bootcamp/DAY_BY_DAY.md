## 第 1 天自测

逐项记录“独立完成 / 提示后完成 / 未完成”，不把示例已有测试当作本人完成。

1. 将任务列表按状态分组，处理缺失字段，解释复杂度。
2. 写两个异步调用，其中一个超时；解释另一个会不会被取消。
3. 给任务查询设计正常、参数非法、不存在三类接口行为。
4. 给 `tasks`、`runs` 写 SQL 查询每个任务最近一次失败运行，考虑时间相同。
5. 给任务诊断写 8 个不同的测试场景及预期依据。
6. 写一个 pytest 测试，主动改坏查询结果，确认测试能失败。
7. 画出模型请求工具、程序执行工具、工具结果回给模型的顺序。
8. 错误答案出现时，如何区分 UI、API、配置、工具数据、模型五层问题？
